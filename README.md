# Lab5Activities

Лабораторна робота №5. Створення та виклик Activity (Android, Java).

## Завдання
Застосунок із чотирьох Activity. На головному екрані (`MainActivity`) меню з чотирьох кнопок:
висота кожної 20% екрана, проміжок 2%, відступи зверху й знизу по 7%, ширина 75%, вирівнювання по центру.

## Екрани
| Кнопка | Activity | Що демонструє |
|---|---|---|
| Навігація | `SecondActivity` | Передавання даних через Intent |
| Інтерактивність | `ThirdActivity` | Лічильник натискань, конфеті |
| Про застосунок | `FourthActivity` | Опис застосунку, пасхалка |
| Вийти | діалог | Підтвердження виходу |

## Особливості
- Перемикач світлої й темної теми (зберігається в `SharedPreferences`)
- Голосове керування українською: «навігація», «інтерактивність», «про застосунок», «темна тема», «світла тема», «вихід»
- Анімовані переходи між екранами
- Макет меню на `ConstraintLayout` із `Guideline` (7% / 20% / 2%)

## Запуск
1. Відкрити проєкт в Android Studio.
2. Дочекатись Gradle Sync.
3. Запустити на емуляторі або пристрої (minSdk 24).
